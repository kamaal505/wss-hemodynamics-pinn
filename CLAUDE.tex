\subsection{1. Project identity}\label{project-identity}

\textbf{Title:} PINN-based Wall Shear Stress Recovery from Sparse, Noisy
4D-flow MRI\\
\textbf{Goal:} Recover wall shear fields from synthetic 4D-flow MRI
(downsampled CFD); characterise dependence on sample density, noise
level, and geometry irregularity.\\
\textbf{Output:} Methods + benchmark paper. Primary artefact: open
benchmark (CFD fields + synthetic MRI inputs + checkpoints). Not a
clinical validation paper.\\
\textbf{Target venues:} CMAME, Computers in Biology and Medicine,
Medical Image Analysis, JCP.

\subsubsection{2.2 Physics (see doc 02 for
equations)}\label{physics-see-doc-02-for-equations}

\begin{itemize}
\tightlist
\item
  Flow model: steady incompressible Newtonian Stokes (Re
  \textless\textless{} 1). Pulsatility, FSI, non-Newtonian: deferred to
  follow-up paper.
\item
  Key parameters: ρ = 1060 kg/m³, μ = 3.5×10⁻³ Pa·s, U\_inlet = 2×10⁻⁵
  m/s → Re ≈ 0.10.
\end{itemize}

\subsubsection{2.3 PINN architecture (see doc 03 for full
spec)}\label{pinn-architecture-see-doc-03-for-full-spec}

\begin{itemize}
\tightlist
\item
  Coordinate-based MLP: input (x,y,z)/L, output (û,v̂,ŵ,p̂). Tanh
  activations \textbf{only} --- never ReLU (breaks second-order
  autograd).
\item
  Optional: Random Fourier Features encoder; hard no-slip via SDF mask.
\item
  Framework: PyTorch 2.x, from-scratch. DeepXDE for prototype only.
\end{itemize}

\subsubsection{2.4 Loss, WSS computation, training
recipe}\label{loss-wss-computation-training-recipe}

\begin{itemize}
\tightlist
\item
  Three loss terms: MRI data fit, Stokes PDE residual + continuity,
  no-slip BC. See doc 03 for formulas and weight defaults.
\item
  WSS via autograd on the trained network --- no finite differences. See
  doc 03.
\item
  Optimiser: Adam → L-BFGS. Cosine LR 1e-3→1e-6. Collocation points
  resampled each epoch. Pressure anchor at one outlet DOF.
\end{itemize}

\tightlist
\item
  Python 3.11+. Type hints throughout. NumPy-style docstrings.
\item
  \textbf{Never} ReLU in PINN backbone. \textbf{Never} jet colormaps.
\item
  All RNG seeds in \texttt{utils/seeds.py} --- never hard-code.
\item
  Prefer functional/pure code; classes for stateful components only.
\item
  Figure output: vector PDF or 600 dpi PNG. One script per paper figure
  (see doc 04).
\item
  Colormaps: viridis/magma/cividis (sequential); RdBu\_r (diverging,
  signed quantities only).
\end{itemize}
